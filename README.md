# 📋 에버노트 백업 도구 GUI
### Evernote Backup GUI — Windows Desktop App

> [evernote-backup](https://github.com/vzhd1701/evernote-backup) v1.14.0 CLI를 감싼 **Windows 전용 GUI 백업 도구** (GUI v1.14.5)입니다.  
> 터미널 없이 버튼 클릭만으로 에버노트 전체 노트를 로컬에 ENEX 형식으로 백업합니다.

---

## ✨ 주요 기능 (Features)

| 구분 | 기능 | 설명 |
|------|------|------|
| 🔐 **인증** | **원클릭 OAuth 2.0** | 브라우저 기반 1회 인증 — 이후 로컬 DB에 토큰 자동 저장 및 재사용 |
| 📋 **편의** | **클립보드 자동 감지** | OAuth URL 복사 시 GUI가 감지하여 자동으로 브라우저를 띄워줌 |
| 🚀 **백업** | **원클릭 일괄 백업** | 동기화(sync) → ENEX 내보내기(export) 자동 순차 실행 |
| ⏹ **제어** | **안전한 백업 중지** | 진행 중 언제든지 취소 가능하며 이미 동기화된 DB는 안전 보존 |
| 📊 **모니터링** | **실시간 진행률 & 로그** | 진행률 바 및 상세 작업 로그를 실시간 확인 |
| 🔍 **버전 감지** | **CLI 버전 호환성 검사** | 시작 시 CLI 버전 호환성을 자동 검증하여 불일치 에러 방지 |
| ⚙️ **내보내기 옵션** | **세부 Export 제어** | 개별 노트 분할, 덮어쓰기, 메타데이터 포함, 날짜 제외, 휴지통 포함 |
| 🎯 **필터링** | **노트북 / 태그 필터** | 특정 노트북 또는 태그만 선택하여 맞춤형 ENEX 내보내기 |
| 🛠 **진단 도구** | **DB 무결성 검사 & 목록 조회** | DB 손상 검사(`manage check`) 및 보관된 노트북 조회(`manage list`) |
| 🌐 **고급 설정** | **글로벌/중국 서버 및 SSL** | Yinxiang(중국) 서버, 시스템 SSL CA, 수동 API 토큰 입력 지원 |
| 📁 **결과 확인** | **폴더 즉시 열기** | 백업 완료 후 내보내기 폴더를 탐색기에서 바로 열기 |
| 📝 **로그 관리** | **작업 로그 파일 저장** | 전체 작업 로그를 `.txt` 파일로 영구 보관 |

## 🚀 시작하기 (Getting Started)

### 요구사항

- **Windows 10 / 11** (64비트)
- **evernote-backup.exe (v1.14.0)** — 이 GUI와 **동일한 폴더**에 배치 필수
- 에버노트 계정 (Evernote 글로벌 또는 Yinxiang 印象笔记)

### evernote-backup.exe 다운로드

👉 [**공식 GitHub 최신 릴리즈 다운로드**](https://github.com/vzhd1701/evernote-backup/releases/tag/1.14.0)에서  
`bin_evernote_backup_1.14.0_win_x64.zip` 파일을 내려받아 압축을 풀면 나오는  
`evernote-backup.exe`를 GUI 프로그램과 **같은 폴더에 놓아주세요**.

### GUI 실행 방법

**방법 1 — Python으로 직접 실행 (개발용)**

```bash
# Python 3.9+ 필요
pip install -r requirements-dev.txt  # pytest 등
python main_gui.py
```

**방법 2 — 빌드된 EXE 사용 (권장)**

[GitHub Releases](https://github.com/cdman28/evernote_backup_gui/releases)에서:
1. `EvernoteBackupGUI_v1.14.5.exe` 다운로드
2. [evernote-backup v1.14.0](https://github.com/vzhd1701/evernote-backup/releases/tag/1.14.0)에서 `evernote-backup.exe` 다운로드
3. 두 파일을 **같은 폴더**에 저장
4. `EvernoteBackupGUI_v1.14.5.exe` 실행

**폴더 구조 (필수)**

```
📁 작업 폴더/
├── EvernoteBackupGUI_v1.14.5.exe  ← ← 이것을 실행!
└── evernote-backup.exe             ← CLI (필수!)
```

> 💡 **처음 사용하시나요?** → [📖 상세 설치 가이드](INSTALLATION_GUIDE.md) 참고

## 📖 사용법 (Usage)

### 1단계 — OAuth 인증

1. **"OAuth 인증 시작"** 버튼 클릭
2. 검은 콘솔 창이 열리고, 브라우저가 자동으로 에버노트 로그인 페이지를 엽니다.
3. 에버노트에 로그인 후 **"일괄 백업 허용 (Allow Bulk Backup)"**을 클릭합니다.
4. 콘솔 창이 자동으로 닫히고 GUI에 **"✅ 인증 완료!"**가 표시됩니다.

> **💡 브라우저가 자동으로 안 열릴 경우**
>
> 콘솔 창에 표시된 `https://...` URL을 복사하여 GUI의 URL 입력란에 붙여넣고 **"🌐 열기"** 버튼을 클릭하세요.  
> 또는 복사만 해도 GUI가 클립보드를 자동 감지하여 브라우저를 열어줍니다.

### 2단계 — 백업 실행 및 옵션 설정

1. **내보내기 폴더** 선택
2. 필요 시 세부 내보내기 옵션 체크 (개별 노트 분할, 특정 노트북/태그 필터 등)
3. **"🚀 백업 시작"** 버튼 클릭
4. 동기화 → ENEX 내보내기 순서로 자동 진행
5. 완료 후 **"📁 폴더 열기"**를 통해 생성된 ENEX 파일 확인

### 3단계 — 정기 백업 및 DB 진단

- 이후 백업은 **"🚀 백업 시작"** 버튼만 누르면 변경된 노트만 신속하게 동기화됩니다.
- DB 무결성이 의심될 경우 **"🔍 DB 무결성 검사"** 버튼을 눌러 상태를 점검할 수 있습니다.
- **"📋 노트북 목록 조회"**를 누르면 백업된 노트북 현황이 로그 창에 즉시 표시됩니다.

## 📦 백업 결과물 (Output)

백업 결과는 표준 `*.enex` 형식으로 저장됩니다.

```
📁 내보내기 폴더/
├── 📓 개인 노트북.enex
├── 📓 업무 자료.enex
├── 📓 스크랩.enex
└── ...
```

ENEX 파일은 **Notion**, **Obsidian**, **Joplin**, **Bear**, **Logseq** 등 대부분의 노트 앱에서 그대로 가져올 수 있습니다.

## ⚙️ 고급 설정 (Advanced)

`[⚙️ 고급 인증/네트워크 설정 ▼]`을 누르면 다음 설정을 변경할 수 있습니다:
- **서버 선택**: 글로벌 에버노트(`evernote`) 또는 중국 인샹비지(`china`)
- **SSL 인증서**: 기업/사내망 보안 환경용 `--use-system-ssl-ca`
- **수동 토큰**: 개발자 토큰 직접 입력 시 `--token` 지원
- **OAuth 호스트**: 로컬 리다이렉트 호스트 지정
